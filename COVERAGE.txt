================================================================================
  OUT OF SCOPE (BY DESIGN)
================================================================================

  ARGUS is a SAST tool — the following capabilities are addressed by adjacent
  security tooling in the Halodoc stack:

    * Full dependency-CVE scanning (SCA)   → osv-scanner · pip-audit · npm-audit · Trivy
    * Runtime / dynamic testing (DAST)     → OWASP ZAP · Burp Suite · Nuclei
    * Container image vuln scanning        → Trivy image · Grype
    * Runtime memory / behavior analysis   → IAST tools · runtime instrumentation
    * SBOM generation                      → Syft · CycloneDX
    * Live secret rotation / vault audit   → separate secret-management stack

  ARGUS integrates with these tools via SARIF output — every finding it emits
  can be consumed by the same dashboards (GitHub Code Scanning, GitLab SAST
  reports, Jenkins Warnings-NG) that ingest results from the tools above.
